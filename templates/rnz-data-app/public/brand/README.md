# Master logo goes here

Put the supplied RICOH logo file here (SVG preferred, or PNG), for example `ricoh-logo.svg`, then set `LOGO_SRC = "/brand/ricoh-logo.svg"` in `src/App.tsx`.

Rules (ricoh-brand-methodology-v12.html, Section 03):

- Master artwork only. Never retype, redraw, recolour, crop or animate it.
- In app headers use the RICOH logo without the tagline. Minimum width 80px on screen where the lock-up is used.
- Keep the protected area clear. Nothing else inside it.
- A new app icon or co-branded mark needs APAC brand approval before release.
