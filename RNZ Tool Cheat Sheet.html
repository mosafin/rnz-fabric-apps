RNZ Tool Cheat Sheet

RNZ tool cheat sheet

Gives apps built in VS Code the Ricoh New Zealand look, and keeps them that way. Make new branded Fabric apps, or re-skin apps you already have (colours, fonts and font weights only) without breaking them.

Release 1.2.0, October 2026. Full guides in the docs folder of the rnz-fabric-apps repository.

Set up once (about 5 minutes)

You need access to the rnz-fabric-apps repository on GitHub (ask the maintainer), Git, Node.js 20 or later, and VS Code with GitHub Copilot.

  1. In VS Code, open a terminal (Terminal > New Terminal) and paste:

    git clone https://github.com/mosafin/rnz-fabric-apps "$HOME/.rnz/rnz-fabric-apps"
node "$HOME/.rnz/rnz-fabric-apps/bin/rnz.mjs" install

  2. Reload VS Code: press Ctrl + Shift + P, type reload window, press Enter.

  3. Open Copilot Chat in Agent mode and type /rnz. Five commands should appear. You never need to install again: the tool updates itself.

The five commands

Type them in Copilot Chat, in Agent mode. Each one asks you or shows a preview before it changes anything.

CommandUse it toChanges files?
/rnz-newCreate a new branded Fabric appCreates a new app folder
/rnz-skinPut the RNZ look on an app you already haveYes, on a new branch
/rnz-updateBring an app up to the latest RNZ releaseYes, on a new branch
/rnz-agentsAdd the builder, QA or reporter agentsAdds files, on a new branch
/rnz-checkSee what's off brandNo

Every time you change an app

Before

  • Open only the app's repository, at its top folder.
  • Commit or stash your work. The tool stops if anything is uncommitted.
  • Pause OneDrive if the repository is in it.

After

  • Try the app on the new branch (npm run dev).
  • Happy: merge the branch.
  • Not happy: switch back and delete the new branch. Your branch was never touched.

The tool never restructures screens, renames or deletes your files, pushes, merges or deploys. If a change would break a build or test that passed before, it undoes itself.

Agents (optional)

AgentDoesNever does
rnz-builderBuilds screens and changes on brand, then runs the checksEdit brand files, commit, push or deploy
rnz-qaReviews a change and lists the problemsChange any file
rnz-reporterUpdates the version and adds a change log entryChange anything else

In Copilot, pick the agent from the agent list. In Claude Code, ask for it by name, for example "use rnz-qa".

Brand rules in one breath

Ricoh Red #CF142B Ricoh Grey #666666 White #FFFFFF Light #F5F5F5
  • Red, white and grey. Red for the main action and key emphasis only.
  • Text is Ricoh Grey, never black. White text only on red or grey.
  • Frutiger, then Arial. Weights 300, 400 and 700 only. Light theme only.
  • The RICOH logo always with its "imagine. change." tagline (the lock-up), at least 80px wide. Never on its own, never as a favicon.
  • NZ English, sentence case, no em or en dashes.

If something goes wrong

The /rnz commands don't show
Reload VS Code and make sure Copilot Chat is in Agent mode.
"The repository has uncommitted changes"
Commit your work, or run git stash -u and bring it back later with git stash pop.
"Deletion of directory ... failed. Should I try again? (y/n)"
Type n and press Enter. OneDrive or the app preview had the folder open; pause OneDrive next time.
Copilot ran a command in the wrong repository
Open only the app's repository in VS Code, or run git yourself with the folder named: git -C "folder" status.
"... was undone, because something that worked before stopped working"
Nothing was changed. Send the full message to the maintainer.
